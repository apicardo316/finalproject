Notes:

In order for useability and testing purposes, I pivoted my app slightly so that anyone can make an account, but then you also have the option to verify your account with a spotify artist account.
When you verify your account (in this version you can choose any artist), your profile will add a new button that will display some public spotify statistics such as popularity, followers, and genres.
Users who do not verify their spotify artist account will not have that button on their profiles, but will still be able to see and click it on verified artist accounts.


This app contains all the required features, as well as these extra features:
External API (25 points)
File Upload/Download (25 points)
In app messaging (25 points)

Also small note, the sign up button will automatically create an account, so make sure to type an email and password first before clicking it.
